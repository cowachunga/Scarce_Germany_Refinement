# Data Point supporting files
The files included in this folder contain all the relevant data points and supporting files to run baseline and optimized runs for scarce_core.py.

## Files
The files are specific to Germany and are seperated by years. They include the following for each folder:

1. Comtrade file for that specific year
2. Indicators file for that specific year
3. Production file for that specific year
4. Reserves file for that specific year
